# Changelog Ujianix

Catatan perubahan Ujianix disusun berdasarkan perubahan dan status pengembangan yang terdokumentasi. Catatan ini tidak menyatakan fitur telah berhasil apabila belum dikonfirmasi melalui pengujian.

## v7 — kandidat rilis publik / versi pengembangan terakhir

### Ditambahkan
- Splash screen Ujianix.
- Akses konfigurasi administrator melalui menu boot (F2), sesuai konfigurasi build.
- Dokumentasi sistem pengawasan peserta.

### Diubah dan diperbaiki
- Penyesuaian konfigurasi boot menu.
- Penyesuaian konfigurasi installer Calamares.
- Penyesuaian lingkungan kiosk dan halaman administrator.
- Perbaikan dan penyempurnaan konfigurasi build untuk persiapan rilis.

### Catatan pengujian dan keterbatasan
- Pengiriman screenshot dan foto webcam pada sistem pengawasan masih memiliki masalah pada build v7 dan belum boleh dianggap berfungsi sepenuhnya.
- Validasi fitur pada ISO hasil build final masih diperlukan sebelum menyatakan build siap digunakan untuk ujian.
- Status keberhasilan boot, installer, kiosk, konfigurasi administrator, dan pengawasan harus merujuk pada dokumentasi pengujian.
